# DailyReportOrganizer

# How to use

- Generate the Report
  - Run the console command to generate the report.
  - Save the output as report.csv.

- Verify Report Data
  - Ensure the Report_Day field is accurate and clean.

- Execute the Cleaning Tool
  - Run DailyClean.exe.
  - A pop-up window will appear.

- Confirm Success
  - A "Done" message indicates the process completed successfully.
  - If the message does not appear, verify that all files are in the correct folders and none have been deleted.
